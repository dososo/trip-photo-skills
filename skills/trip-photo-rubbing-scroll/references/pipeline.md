# 每一步怎么算

## build

- 读照片：按 EXIF 方向转正，按内嵌 ICC 转 sRGB，统一缩到 900 像素高；保存时不写 EXIF 和 ICC。
- 排序：按拍摄时间从早到晚；卷首（最右）是最早的一段，往左展开（手卷的读法）。
- 拓片白纹（`scripts/rubbing.py`）：拓片上，石面平整处上了墨是黑的，刻线和凹处碰不到墨，留白。
  - 刻线 = 亮度的细节高通：`L − 高斯(L, 5)`，减阈值 0.012 后除以 0.03，截到 0–1。瓦楞、窗格、山脊、树冠的亮边都会留白。
  - 受光面 = 粗尺度高通：`L − 高斯(L, 30)`，弱一些地叠上去，让山体有体积。
  - 石面剥蚀：多尺度噪声成片地吃掉一部分白纹，像年代久的碑。
  - 天空、水面这类平滑的面没有细节，自然是墨黑的。
- 照片太多时：按白纹平均强度（纹理丰富度）排序，同一天只先取一张。

## html

- 运行时 `assets/runtime/scroll.bundle.js` 由 `src/app.js` + `src/scroll-core.js` + three.js r186 打包（`scripts/build_runtime.sh` 可复现）。
- 白纹和照片以 JPEG data URL 内嵌；地名、印文、日期以 JSON 内嵌。网页不发任何网络请求。

## 渲染（scroll-core.js）

- 每段一张 384×288 的「擦拭蒙版」（半精度浮点，乒乓更新）：R = 擦了多少，`R' = 1 − (1 − R)(1 − 覆盖)`，多次擦会叠深，次序无关；G = exp(−第一次擦透的时刻 / 30)。
- 白纹显出：`smoothstep(0.1 + 0.32·颗粒, 0.78, R)`，颗粒噪声让擦的边缘像干拓。
- 晕回彩色：取周围 12 点的平均擦透时刻，过 `delay` 秒后按低频噪声决定的先后从里往外晕开，前沿压一道水迹线。
- 覆盖量和手指速度无关：每走 10 屏幕像素叠 0.1。
- 盖印：页面另用 24×18 的粗网格跟踪覆盖，超过 55% 的格子擦透就盖印；印文的年季由拍摄日期换算成干支（立春前算上一年）+ 季节。
