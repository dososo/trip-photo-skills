# 数据去向

| 数据 | 去哪 | 说明 |
|---|---|---|
| 原照片 | 只被读取 | 不修改、不移动、不上传 |
| `work/src/*.jpg` | 本机输出文件夹 | 转 sRGB、长边 2400，不含 EXIF / GPS / 机型 |
| `work/manifest.json` | 本机输出文件夹 | 含原文件路径、拍摄时间、GPS，只用于挑片去重；交付后可删除整个 `work/` |
| 分割模型权重 | 从 Hugging Face 下载到本机缓存 | 只下载一次；下载的是模型，不传照片 |
| `lantern.html` | 本机输出文件夹 | 只含 8 格剪纸、8 张裁成方形的照片、你填的地名和日期；不含 GPS、机型、原文件名 |

需要你自己判断的两件事：

1. **AI 助手看图**：如果你让 Claude Code、Codex 之类的助手打开 `picks_sheet.jpg` 或任何照片，图片会作为对话内容发给对应的模型服务商。本 skill 默认只把路径给你，由你自己打开。
2. **分享网页**：`lantern.html` 里有 8 张照片的方形裁切。分享前确认里面没有不想公开的人、车牌、门牌。默认会跳过人物面积超过 0.2% 的照片，但远处很小的人影可能仍在画面里。
