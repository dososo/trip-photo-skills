# 数据去向

| 步骤 | 在哪里处理 | 会不会离开这台电脑 |
|---|---|---|
| `prepare` 工作副本 | 本机 | 不会。工作副本去掉全部 EXIF / GPS / 机型 / ICC |
| `facts` 取事实 | 本机 | 不会。只读拍摄时间，不读 GPS |
| `ridge` / `song` / `validate` / `stills` / `render` | 本机 | 不会 |
| 第 4 步「画」 | 生图服务（例如 OpenAI） | **会**：选中的 3 张工作副本会上传。必须先征得用户同意 |
| AI 助手查看照片 | 助手的模型服务商 | **会**：图片会作为对话内容发送。用户同意前只给路径 |

- 首次运行会下载：UperNet 权重（Hugging Face）、VSCO-2-CE 采样（GitHub）、霞鹜文楷字体（GitHub）。下载不携带任何照片或个人信息。
- 信里只写城市 / 景区级地名，不写住址、酒店名。
